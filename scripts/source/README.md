# Franchise logo sources

Place the **Norwin Atlanta Lions** crest here as:

- `norwin-atlanta-lions.jpg` (preferred — full-color crest on white, as from design)

Then from repo root:

```bash
npm run logos:atlanta-lions
```

Or pass any JPG/PNG path:

```bash
node scripts/update-atlanta-lions-logo.mjs path\to\norwin-crest.jpg
```

Do **not** use `atlanta-lions-final.pdf` for Norwin — that PDF is an older laurel-wreath mark, not the current Norwin crest.
